# Deepali Harish — Portfolio

Plain HTML/CSS/JS, no build step.

**Run locally:** double-click `index.html`, or for the full experience run
`python -m http.server 8000` in this folder and open http://localhost:8000

**Edit project pop-ups:** `main.js` → `PROJECTS` (add `overview`, `problem`, `research`, `process`, `outcome`, `reflection` text per project).

**Go live (GitHub Pages):** push this folder to a repo → Settings → Pages → Deploy from branch → `main` / root.
